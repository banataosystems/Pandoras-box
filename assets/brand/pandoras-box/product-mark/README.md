# Pandora's Box product mark

`2165-original.jpg` is the exact owner-supplied artwork. Its uploaded name was
`2165.png`, but the bytes are JPEG/JFIF, so the repository extension reflects
the real encoding without changing the file.

The `derived/` directory contains deterministic delivery assets only. The UI
series crops excess outer black canvas while preserving the complete artwork
and a safe margin. The launcher/PWA series retains the full original square so
the complete mark remains within platform-safe areas.

Do not redraw, recolor, invert, trace, animate, remove the black field, or use a
generic apple as a fallback. In-product rendering must use `contain` and the
accessible label `Pandora's Box`.
