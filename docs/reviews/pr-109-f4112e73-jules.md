## MCP Response Envelopes & Structured Content Assessment

MCP specification compatibility requires structured tool responses to return valid object shapes for `structuredContent`:
```javascript
function structuredToolContent(value) {
    if (value && typeof value === "object" && !Array.isArray(value)) return value;
    if (Array.isArray(value)) return { items: value };
    return { value: value ?? null };
}
```
- Plain objects `{ ... }` are preserved directly.
- Array results are wrapped as `{ items: [ ... ] }`.
- Primitives (`string`, `number`, `boolean`) and `null` are wrapped as `{ value: value ?? null }`.
- The primary JSON string representation in `content[0].text` (`JSON.stringify(value)`) remains unchanged, preserving full text backward compatibility.
